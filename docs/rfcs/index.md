# Request for comments

An RFC is a written proposal for a substantial change that has not yet become
an accepted Sagan rule. RFCs make the problem, proposed syntax or behavior,
alternatives, migration cost, and unresolved questions reviewable before code
commits the project to the design.

- [Proposed RFCs](proposed/index.md) are still under discussion.
- [Accepted RFCs](accepted/index.md) are approved for implementation or already
  reflected in the language.
- [Rejected RFCs](rejected/index.md) are preserved with the reason they were
  declined.

An RFC is not language documentation. Until accepted and implemented, examples
inside it must not be presented elsewhere as working Sagan.

Use the [RFC template](template.md) for a new proposal.
