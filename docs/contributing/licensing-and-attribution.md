# Licensing and attribution
Sagan contains foundations derived from Zachary Westerman's
[Schematic](https://github.com/ZacharyWesterman/schematic), which is licensed
under GPLv3.

Contributors must:

- retain applicable copyright, license, and attribution information;
- identify externally sourced or adapted code;
- preserve GPLv3 obligations when redistributing derived work;
- avoid removing provenance because a surrounding component was rewritten; and
- keep project documentation clear about Schematic's role.

Before importing a dependency, confirm its license is compatible with the
project's obligations. Legal uncertainty should be resolved before distribution,
not papered over in documentation.
