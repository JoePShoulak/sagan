    Language tour

    This tour introduces the intended Sagan language, not an executable tutorial. The tokenizer and parser recognize the documented current syntax, and the first semantic pass resolves scopes and names, but type-checking and execution are not implemented.

    Follow the tour through values and variables, functions, classes and interfaces, control flow, and errors. The language reference tracks which details are settled, provisional, or open.
