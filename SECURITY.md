# Security policy

Sagan is a small, best-effort project with no response-time SLA. Only the
latest stable release is supported.

Please report suspected vulnerabilities through GitHub's private vulnerability
reporting feature rather than a public issue. Include affected versions,
reproduction details, impact, and any known mitigation. Reports will be
validated privately when practical. A fix and GitHub security advisory will
normally be published together, with affected versions and mitigations noted.

Preview releases receive no security backports. Published release artifacts and
tags are immutable; a security correction is issued as a new patch release.
